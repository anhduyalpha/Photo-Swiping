FEATURE 1 — DUPLICATE DETECTION

Goal:
Group visually similar images so user can delete quickly.

Implementation strategy:

1. Generate image embeddings OR perceptual hashes:
   Choose one:

   * Perceptual hash (pHash / dHash) → lightweight, fast
   * OR lightweight embedding model (MobileNet / similar)

2. Compare similarity:

   * Use Hamming distance (for hash)
   * OR cosine similarity (for embeddings)

3. Cluster images:

   * Group similar photos into clusters
   * Each cluster shows:

     * best photo (auto-selected)
     * duplicates (to delete)

4. UI:

   * Show stack per cluster
   * “Keep best, delete rest” button

---

FEATURE 2 — BLUR / LOW QUALITY DETECTION

Goal:
Auto-flag bad photos.

Implementation:

* Use variance of Laplacian (classic blur detection)
* Optionally:

  * brightness detection
  * noise estimation

Output:

* Mark photos as:

  * “Blurry”
  * “Low quality”

UI:

* Separate section: “Review low quality photos”
